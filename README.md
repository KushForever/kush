# KUSH

Маршруты по Петербургу на сегодня с бронированием. Сайт живёт на Netlify и обновляется сам после каждого изменения в этом репозитории.

## Где что лежит

- `index.html` — весь сайт: экраны, база мест, подбор маршрута.
- `img/` — свои фото мест. Имя файла = id места, формат jpg (например `solids.jpg`). Список id — в таблице «KUSH: места и фото».
- `netlify/functions/api.mjs` — сервер: бот в Telegram, уведомления, заявки, поддержка, ИИ.
- `netlify.toml` — настройки Netlify.
- `fonts/` — шрифты Unbounded и Onest.

## Переменные в Netlify

`TG_BOT_TOKEN`, `TG_ADMIN_ID`, `TG_SECRET` — бот. `ANTHROPIC_API_KEY` — ИИ (по желанию). `BOT_BOOKING=off` — выключить «Бот бронирует».
После смены переменных нужен новый деплой: Deploys → Trigger deploy.

## Как добавить фото

На github.com откройте папку `img` → Add file → Upload files → перетащите фото → Commit changes. Через минуту фото на сайте.

## Instagram: ролик дня

1. ИИ-агент (запланированная задача Claude) раз в день делает ролик в Higgsfield и добавляет запись в `content/posts.json`:
   `{"date":"2026-11-17","video_url":"https://…mp4","caption":"…"}`.
2. Netlify пересобирает сайт, срабатывает `deploy-succeeded`, и фоновая функция `ig-publish-background` публикует ролик как Reels с пометкой «создано ИИ».
3. Результат приходит в Telegram. Пока не заданы `IG_USER_ID` и `IG_TOKEN`, ролик просто присылается в Telegram, чтобы выложить вручную.

## Оплата через ЮKassa

1. Подключи магазин в ЮKassa (для самозанятых тоже можно) и возьми в личном кабинете `shopId` и секретный ключ (Интеграция → Ключи API).
2. В Netlify → Environment variables добавь `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`, затем сделай новый деплой.
3. Проверка: `/api/health` должен показать `payments: ЮKassa подключена`.

Платёж двухстадийный: при оплате деньги замораживаются, а списываются, когда сайт начисляет токены (`/api/pay/check`). Если человек оплатил, но не вернулся на сайт, ЮKassa сама отменит холд через несколько дней и вернёт деньги. Цены пакетов заданы в двух местах: `TOKEN_PACKS` в index.html и `PACKS` в netlify/functions/api.mjs — меняй оба.
